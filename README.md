# Sales Data Analysis

A Python-based data analysis project that explores sales data to identify business trends, customer behavior, and key performance metrics. The project uses data analysis and visualization techniques to generate meaningful insights that can help improve business decision-making.

## Features

- Load and analyze sales dataset
- Clean and preprocess data
- Handle missing values
- Generate summary statistics
- Visualize sales trends
- Identify top-performing products
- Analyze sales by category and region
- Generate business insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## Workflow

1. Load the sales dataset.
2. Clean and preprocess the data.
3. Handle missing or duplicate values.
4. Perform Exploratory Data Analysis (EDA).
5. Generate visualizations.
6. Analyze sales trends.
7. Draw business insights.

## Analysis Performed

- Total Sales Analysis
- Monthly Sales Trend
- Product-wise Sales
- Category-wise Performance
- Regional Sales Analysis
- Top Selling Products
- Revenue Summary

## Visualizations

- Bar Chart
- Line Chart
- Pie Chart
- Histogram

## How to Run

Clone the repository

```bash
git clone https://github.com/NarasimhaMurthy1107/sales-data-analysis.git
```

Move into the project directory

```bash
cd sales-data-analysis
```

Install dependencies

```bash
pip install pandas numpy matplotlib
```

Run the project

```bash
python sales_data_analysis.py
```
